# Cheat Sheet 10: paradigmas de programación

- **Imperativo** (*imperative*): se le dan a la computadora instrucciones paso a paso que cambian el estado del programa, como actualizar variables dentro de un ciclo.
- **Procedural** (*procedural*): código imperativo organizado en funciones, cada una con una sola tarea; por ejemplo, un programa con una función para leer los datos, otra para procesarlos y otra para imprimir el resultado.
- **Orientado a objetos** (*object-oriented*): los datos y las funciones que trabajan con ellos se agrupan en objetos, que se construyen a partir de clases (por ejemplo, una clase `student` con un nombre, una lista de calificaciones y un método que calcula el promedio).
- **Funcional** (*functional*): los programas se construyen combinando funciones que regresan valores nuevos en lugar de cambiar los existentes, sin ciclos que actualicen variables.
- **Declarativo** (*declarative*): se describe qué se quiere, no cómo obtenerlo. SQL es el ejemplo clásico: se piden los renglones que cumplen una condición, y la base de datos decide cómo encontrarlos.
- **Lógico** (*logic*): se establecen hechos y reglas, y el sistema encuentra las respuestas que los cumplen (Prolog es el ejemplo más común).
- **Orientado a eventos** (*event-driven*): el código se ejecuta en respuesta a eventos, como clics o mensajes, como en las páginas web y las aplicaciones.
