# Cheat Sheet 3: estructuras de control

## Loops (repeat code)

- for: repeat once for each item in a sequence
- while: repeat as long as a condition is true

### Loop helpers

break: exit the loop immediately
continue: skip to the next pass of the loop

## Conditionals (choose code, run it once)

- if / elif / else: run a block only if a condition is true
- match / case: pick one block based on a value (newer Python, less common in exercises)

## Error handling 

try / except: run code, and jump somewhere else if it causes an error

So for c in s is a loop, but if c.isalpha(): is a conditional, not a loop.
