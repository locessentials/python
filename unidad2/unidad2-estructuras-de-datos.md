# Unidad 2: Estructuras de datos

## ENG y ESP

0. Complejidad (Big O): cómo medir el costo de cada operación, el criterio para elegir una estructura
1. Arrays (arreglos): Fixed-size block of elements accessed by index. The foundation for most other structures.
2. Hash tables (tablas hash or tablas de dispersión): Store key-value pairs with near-instant lookup. Python’s dict is one.
3. Stacks (pilas): LIFO, last in, first out. You push onto and pop from the top. Used for undo, recursion, and checking balanced parentheses.
4. Queues (colas): FIFO, first in, first out. You add at the back and remove from the front. Used for task scheduling and breadth-first search.
5. Linked lists (listas ligadas or enlazadas): Nodes where each one points to the next. Easy to insert and delete, but slow to access by position.
6. Trees (árboles): Hierarchical nodes with a root and children. The binary search tree (árbol binario de búsqueda) is the most common one in exams.
7. Heaps (montículos): A tree that always keeps the smallest (or largest) element on top. Used for priority queues (colas de prioridad).
8. Graphs (grafos): Nodes connected by edges, used for networks, maps, and routes. Usually stored as an adjacency list or adjacency matrix.

## ESP

0. Complejidad (Big O): cómo medir el costo de cada operación, el criterio para elegir una estructura
1. Arreglos: bloque de elementos accedidos por índice; en Python, `list` es un arreglo dinámico
2. Tablas hash (tablas de dispersión): pares clave-valor con búsqueda casi instantánea; en Python, `dict` y `set`
3. Pilas: LIFO, el último en entrar es el primero en salir; se usan para deshacer, recursión y paréntesis balanceados
4. Colas: FIFO, el primero en entrar es el primero en salir; se usan para planificar tareas y en BFS
5. Listas ligadas (enlazadas): nodos que apuntan al siguiente; inserción fácil, acceso por posición lento
6. Árboles: nodos jerárquicos con una raíz e hijos; el árbol binario de búsqueda es el más común en exámenes
7. Montículos: árbol que mantiene el menor (o mayor) elemento arriba; base de las colas de prioridad
8. Grafos: nodos conectados por aristas; se representan con lista o matriz de adyacencia
