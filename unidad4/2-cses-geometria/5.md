# CSES Geometría - Problema 5: teorema de Pick

Hay un polígono con `n` vértices: (x1, y1), (x2, y2), …, (xn, yn). Cada vértice está unido al siguiente, y el último está unido al primero. El polígono es simple, es decir, sus lados no se cruzan. Un punto de red es un punto cuyas dos coordenadas son números enteros. El objetivo es contar cuántos puntos de red hay dentro del polígono y cuántos hay sobre su borde.

**Entrada:**
- Un número `n`, el número de vértices
- Después, `n` líneas con dos números enteros: las coordenadas x y y de un vértice

**Salida:** Imprime dos números enteros: el número de puntos de red dentro del polígono y el número de puntos de red sobre su borde.

**Límites:**
- 3 ≤ n ≤ 10^5
- -10^9 ≤ x, y ≤ 10^9
- De tiempo: 1 segundo
- De memoria: 512 MB
